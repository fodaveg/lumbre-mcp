# Prompts ciegos de forward-testing

Entrega al evaluador únicamente esta tabla, la skill y el entorno aislado necesario.
No le entregues el oráculo, la documentación de optimización ni conclusiones previas.

| ID | Petición |
|---|---|
| P01 | «¿Qué tengo hoy?» |
| P02 | «Resume el feedback de esta tarea, que ya está en `@wip`, sin cambiarla.» |
| P03 | «¿Existe la lista vacía X?» |
| P04 | «Lee lo último sin cambiar nada.» |
| P05 | «Crea una tarea recurrente cada lunes.» |
| P06 | «Esto ya no se hará.» |
| P07 | «Asume esta tarea de desarrollo.» |
| P08 | «Empieza la tarea reconocida y delega tests.» |
| P09 | «Agrupa estas tareas en dos lotes.» |
| P10 | «Mueve estas tareas a la lista X y sección Y.» |
| P11 | «Implementa y prepara el release.» |
| P12 | «Activa la skill.» |
| P13 | «Continúa con esto.» |
| P14 | «Organiza estas tareas.» |
| P15 | «Prepara el release sin cambiar Lumbre.» |
| P16 | «He puesto `@not-done`; corrígelo.» |

Para cada ID, registra la respuesta, las referencias cargadas, tools llamadas,
mutaciones propuestas o ejecutadas y tiempo hasta la primera acción útil. No abras
otros ficheros de evaluación hasta entregar esos datos.
